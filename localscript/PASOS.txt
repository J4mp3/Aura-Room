LO QUE HACÉS VOS
=================================================================
[ ] 1. Probar todo en la compu: abrí tarjeta/index.html, sellos/index.html (botón «Probar con datos de ejemplo») con doble clic.
[ ] 2. Subir a GitHub (la primera vez):
       - github.com → + → New repository → nombre: aura-room → Public → Create repository.
       - "uploading an existing file": arrastrá tarjeta, sellos e index.html (y .gitignore / .nojekyll
         si los ves: son opcionales). Todo menos localscript → Commit changes.
       - Settings → Pages → Deploy from a branch → rama main, carpeta / (root) → Save.
       - En 1 o 2 minutos andan las direcciones de arriba.
[ ] 3. Tarjeta de fidelidad · script de Google APARTE (no es el de la app), CON LA CUENTA DE GOOGLE DE LA PERSONA:
       - script.google.com → Nuevo proyecto → nombre "Aura Room – Tarjeta de fidelidad".
       - Borrá lo que trae y pegá localscript/tarjeta-script.gs (la clave ya va adentro) → Guardar.
       - Arriba elegí la función probarTarjeta → Ejecutar → Revisar permisos → aceptá (así se crea el archivo de datos en su Drive).
       - Implementar → Nueva implementación → Aplicación web → Ejecutar como: Yo, Quién tiene acceso: Cualquier usuario
         → Implementar → copiá la URL (termina en /exec).
       (Ya cargaste una: https://script.google.com/macros/s/AKfycbx5gW6fsyKefYD1dcERnYQzWjdXRYRGADD2ZL-O0qfCU672vCZYMBiN_sRKFvrQ247vmw/exec)
[ ] 4. Pegá esa URL en el TarjetaEditor → Conexión y publicar → Guardar,
       y volvé a subir tarjeta/ y sellos/. Sin la URL, la página no puede sumar clientes.
[ ] 5. Imprimí el cartel para el mostrador: localscript/qr/cartel-tarjeta.png (escanealo antes para probarlo).
[ ] 6. Pasale a la persona: el link de la app de sellos (https://github.com/J4mp3/Aura-Room/sellos/), el link de conexión de la tarjeta (o el QR localscript/qr/conectar-celular.png), el PIN de la tarjeta (4211) y el Manual-user-tarjeta.html.
[ ] 7. Cada vez que cambies algo: Guardar en el editor → volver a subir lo que cambió (app/, web/, tarjeta/, sellos/...).
       Los datos de la persona no se pierden: viven en su celular y en su Drive.

=================================================================
LO QUE HACE LA PERSONA (el emprendimiento)
=================================================================
[ ] 1. Tarjeta: en cada celular del negocio abrir el link de conexión (se conecta solo) y después, en ese mismo
       navegador, instalar la app de sellos: Android (Chrome) menú ⋮ → Instalar app · iPhone (Safari) Compartir → Agregar a inicio.
[ ] 2. En la app de sellos: Ajustes → poner quién usa el celular, revisar los premios y cambiar el PIN si quiere.
[ ] 3. Compartir el link de la tarjeta (https://github.com/J4mp3/Aura-Room/tarjeta/) en Instagram y WhatsApp, y dejar el cartel con el QR a la vista.
       Cada vez que alguien paga: «Escanear tarjeta» en la app y listo, el sello se suma solo.
